## 3. Ablation — 모든 설계 결정이 검증되었다

학습된 가중치를 고정하고 **입력만 바꿔** 측정했다 (재학습 없음).

| 설정 | PSNR | SSIM | Δ PSNR |
|---|---|---|---|
| **iter9 전체 (기준)** | **28.342** | **0.8830** | — |
| σ = 0 | 21.342 | 0.5921 | **−6.999** |
| impulse 맵 제거 | 23.595 | 0.7028 | **−4.747** |
| σ 뒤섞음 | 24.770 | 0.7548 | **−3.572** |

| σ × 2 | 25.908 | 0.8341 | −2.434 |

### 3.1 핵심 아이디어가 +2.947 dB 로 확인되었다

`iter3` 은 impulse **맵** 은 줬지만 DC step 의 `D·Y` 는 여전히 impulse 가 든 raw `y` 로 계산했다.
impulse 가 `1/D` 를 타고 전역 링잉으로 퍼져 **매 반복마다 오염이 재주입**되던 문제다.

`ŷ` 로 교체한 효과가 **−2.947 dB (raw 로 되돌렸을 때)** 로 측정되었다.
사전에 해석적으로 예측한 값(val ALL `Wiener(ŷ) − Wiener(y) = +1.833`)보다 **오히려 크다.**
DC step 은 4회 반복되므로 오염 제거 효과가 누적된 것으로 보인다.

### 3.2 day3 의 σ ablation 무효를 재확인했다

| | iter3 | **iter9** | day3 |
|---|---|---|---|
| σ 뒤섞음 Δ | −5.42 | **−3.572** | **±0.00** |
| σ = 0 Δ | −7.88 | −6.999 | −13.61 |

iter3·iter9 모두 뒤섞으면 3~5 dB 떨어지는데 day3 는 소수점 4자리까지 동일했다.
**day3 의 "뒤섞음" ablation 은 모델에 도달하지 않는 경로를 측정한 것**이 두 번 확인되었다.

### 3.3 `frac_neg` 가 rician 을 3.4 dB 지탱한다

`iter6_review.md` 4.2 에서 Parseval σ̂ 가 **rician 만 −14.9% 과소추정** 하는 것을 실측했고,
`frac_neg` (rician 판별 100%, 25/25) 를 주면 네트워크가 보정을 학습할 것이라고 예측했다.

ablation 이 이를 확인한다: `frac_neg` 를 0 으로 막으면 **−3.424 dB** 다.
iter6 이 rician 에서 baseline 에 지던 문제(20.734 vs 21.264)가
iter9 에서 **22.555** 로 해결되었고, 그 근거가 수치로 남았다.

### 5.1 하한 검증 셀의 결함

셀 23 이 이렇게 출력했다.

```
Wiener(y) — iter3 하한   16.601
Wiener(ŷ) — iter9 하한   15.914
하한 상승 : -0.686 dB      <- 잘못된 결론
```

원인은 **표본이다.** 이 셀은 `DataLoader(val_ds, batch_size=8)` 의 **첫 배치 8개만** 쓴다.
`StratifiedValDataset.combos` 는 `(이미지, noise, σ층)` 순서로 열거되므로
첫 8개는 이미지 0 의 gaussian 3층 + rician 3층 + uniform 2층이고 **S&P 가 통째로 빠진다.**
`ŷ` 의 이득은 S&P 에 집중되므로(+5.565) 편향이 결과를 뒤집었다.

같은 노트북의 셀 17(전체 516 조합 τ 스윕)이 정답을 준다.

| τ | ALL | gaussian | rician | uniform | S&P |
|---|---|---|---|---|---|
| raw | 14.798 | 16.152 | 13.244 | 15.425 | 14.370 |
| **1.5 (사용값)** | **+1.833** | +0.616 | +0.989 | +0.163 | **+5.565** |
| 1.0 | +2.481 | +1.404 | +1.805 | +0.990 | +5.726 |

**셀 23 은 전체 val 을 쓰도록 고쳐야 한다.** 내 설계 실수다.

> 참고: 이 표는 내가 로컬에서 사전 계산한 값(`raw 14.798`, `τ=1.5 → 16.631`)과

## 6. 남은 두 가지 수

### 6.1 T=5, 6 추론 시험 (재학습 없음)

`denoisers[3]` 과 `log_lam[3]` 을 재사용해 stage 를 늘린다. 5분이면 확인된다.

```python
_m = RESULTS["unrolled9"]["model"]
_dn, _lam, _T0 = _m.denoisers, _m.log_lam, _m.iters
_m.denoisers = torch.nn.ModuleList(list(_dn) + [_dn[-1], _dn[-1]])
with torch.no_grad():
    _m.log_lam = torch.nn.Parameter(torch.cat([_lam.data, _lam.data[-1:], _lam.data[-1:]]))
for _T in (4, 5, 6):
    _m.iters = _T
    _ps = []
    with torch.no_grad():
        for _d in test_loader:
            _lb = _d[DataKey.Label].to(config.device); _mm = _d[DataKey.Measure].to(config.device)
            _ps += calculate_psnr(finalize(_m(_mm)), _lb).flatten().tolist()
    print(f"T={_T}: {np.mean(_ps):.3f}")
_m.denoisers, _m.log_lam, _m.iters = _dn, _lam, _T0
```

T3→T4 가 +0.952 였으므로 **T=5 에서 +0.2~0.5** 가능성이 있다.
학습된 stage 가 아니라 재사용이므로 악화될 수도 있는데, 그러면 되돌리면 된다.
